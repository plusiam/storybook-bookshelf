# 📚 우리 반 그림책 도서관 (storybook-bookshelf)

학생이 만든 그림책을 **책장에 꽂아 두고 진짜 책처럼 펼쳐 보는** 인터랙티브 뷰어입니다.

👉 **[직접 체험하기](https://plusiam.github.io/storybook-bookshelf/)**

## 무엇을 하는 앱인가요?

[스토리보드 앱](https://plusiam.github.io/picturebook-storyboard/)에서 이야기를 쓰고 그림을 그려 내보낸 **JSON 파일**을 이 앱의 책장에 끌어다 놓으면, 페이지가 넘어가는 그림책으로 변신합니다. 책장(라이브러리)은 이 기기의 브라우저(IndexedDB)에 저장되어 다음에 다시 열어도 그대로 남아 있습니다.

## 학년 · 교과

- **대상**: 초등 3~6학년, 학급 공용
- **교과**: 도덕·국어·창의적 체험활동 등 그림책 만들기 프로젝트
- **활용**: IB 학습자상 그림책 프로젝트 등 학생 창작물 감상·발표

## 사용 시나리오

1. **그림책 만들기** — 스토리보드 앱에서 이야기를 완성하면 JSON 파일로 저장됩니다.
2. **책장에 꽂기** — JSON 파일을 이 화면에 끌어다 놓거나 ＋ 슬롯을 클릭해 불러옵니다.
3. **펼쳐 보기** — 책등을 클릭하면 책이 펼쳐집니다. 키보드 ← → 또는 스와이프로 페이지를 넘깁니다.
4. **발표하기** — 전자칠판에서는 ⊞ 꽉 찬 화면 또는 🗖 전체화면(F키)으로 크게 봅니다.
5. **인쇄·백업** — 🖨 버튼으로 A4 책 형태 PDF 인쇄, 책등의 ↓ 버튼으로 JSON 다시 내보내기.

## 주요 기능

- 📖 **3가지 펼침 방식** — 두 면 / 그림+글 / 한 면
- 🎨 **꾸미기** — 테마·표지·글꼴·페이지 레이아웃 각 4종, 글자 크기 조절
- 📚 **책장 영속화** — IndexedDB에 라이브러리 저장, 책별 읽던 위치 복원
- 📱 **반응형** — 폰·태블릿·PC 지원, 모바일 스와이프
- 🖨 **PDF 인쇄** — A4 가로 2면 책 레이아웃

## 기술

빌드 도구 없이 동작하는 정적 웹 앱입니다. React 18(UMD) + Babel Standalone을 CDN으로 불러와 브라우저에서 JSX를 컴파일합니다. GitHub Pages `main` 브랜치에 그대로 배포됩니다.
